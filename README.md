# AI Voice Chatbot 🤖🎤

A browser-based AI voice chatbot built with vanilla JavaScript using the **Web Speech API** for real-time speech-to-text and text-to-speech. Designed with a Dialogflow-ready architecture for NLP integration.

## Live Demo
👉 [Try it here](https://jainayu51998-hub.github.io/ai-voice-chatbot)

## Features
- 🎤 Voice Input — real-time speech-to-text via Web Speech API
- 🔊 Voice Output — text-to-speech bot responses
- 💬 Text Input — type messages with Enter or Send button
- 💡 Quick Chips — one-tap suggested messages
- 🧠 Conversational Logic — intent-based responses (Dialogflow integration planned)

## Tech Stack
| Layer | Technology |
|---|---|
| Frontend | HTML5, CSS3, JavaScript (ES6) |
| Voice Input | Web Speech API (SpeechRecognition) |
| Voice Output | Web Speech API (SpeechSynthesis) |
| NLP (planned) | Google Dialogflow |
| Deployment (planned) | Google Cloud Platform |

## How to Run
1. Clone the repo:
   ```bash
   git clone https://github.com/jainayu51998-hub/ai-voice-chatbot.git
   ```
2. Open `index.html` in Chrome (recommended for Speech API support)
3. Type or click 🎤 to speak
